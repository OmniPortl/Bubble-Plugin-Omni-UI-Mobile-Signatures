# Omni UI | Signatures Mobile & Web — standalone source

This folder is the implementation source of truth for the mixed Bubble plugin.

- `src/` contains the strict TypeScript source for **Web Signature Pad**.
- `dist/` contains self-contained Bubble function expressions generated by `npm run build`.
- `element_source/component.js` contains the separate Bubble native-mobile component source for **Mobile Signature Pad**.
- `local-preview/` runs the compiled web lifecycle locally with fixture-backed Bubble properties.

The GitHub plugin repository is a generated Bubble code-layout artifact. Do not copy this folder into that repository. Use Bubble Plugin Builder reconciliation so the current Bubble opaque IDs and metadata remain intact.

Run `npm run check` before reconciliation and `npm run preview:check` after preparing the local preview.
